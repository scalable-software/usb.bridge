Transport Discovery Demo

The symmetric Transport contract, live: Serial and HID answering the same API.

This demonstrates the discovery / permission layer we have built so far — supported(), requestPermission(), granted(), forget(), and the onconnect/ondisconnect events. Both columns run the identical contract over different browser APIs; only the filter and the concrete class differ. Reading and writing bytes (the Connection layer) is the next roadmap step and is not here yet. Needs Chrome or Edge on desktop.
